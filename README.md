# MinimalPersonApi
Lightweight Web Service API built with ASP.NET Core 10 (**Minimal API**). It manages a collection of `Person` entities, demonstrating clean architecture, DTO (Data Transfer Object) patterns, and business logic validation. This project uses an **In-Memory** database. All tests for endpoints are located in `MinimalPersonApi.http` file.

## Tech Stack
- **Framework:** .NET 10 (ASP.NET Core Web API)
- **Language:** C# 14
- **Database:** In-Memory
- **ORM:** Entity Framework Core (In-Memory)
